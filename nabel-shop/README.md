# Nabel — интернет-магазин восточных ароматов

Сайт готов и лежит в этой папке. Дальше — простая инструкция, как всё
запустить и редактировать, без единой строчки программирования.

## 1. Как открыть сайт на MacBook

Есть два способа.

### Способ А (самый простой) — просто открыть файл

1. Найдите в этой папке файл `index.html`.
2. Дважды кликните по нему — он откроется в браузере.

Этого достаточно, чтобы посмотреть сайт. Но у браузеров есть ограничение:
при прямом открытии файла (`file://...`) может не работать подгрузка
некоторых частей сайта. Поэтому для полноценной работы (особенно чтобы
всё точно работало одинаково, как у покупателей) лучше способ Б.

### Способ Б (рекомендуется) — через локальный сервер

1. Откройте приложение **Терминал** (Programs → Utilities → Terminal,
   либо через Spotlight: `⌘+Пробел`, напишите "Terminal").
2. Перетащите папку `nabel-shop` в окно терминала — так путь к папке
   впишется автоматически. Нажмите Enter.
   (Или впишите вручную: `cd` и через пробел путь к папке.)
3. Введите команду и нажмите Enter:

   ```
   python3 -m http.server 8000
   ```

   (Если MacBook попросит установить Python — согласитесь, это
   стандартный компонент macOS.)

4. Откройте браузер и перейдите по адресу:

   ```
   http://localhost:8000
   ```

5. Чтобы остановить сервер — вернитесь в Терминал и нажмите `Control + C`.

Всё, сайт работает у вас локально. Когда будете готовы показать сайт
в интернете — эту же папку нужно будет загрузить на хостинг (например,
Vercel, Netlify, timeweb, reg.ru и т.д. — это уже отдельный шаг, можно
попросить помочь с этим отдельно).

```
│   └── pages.css         — стили для каталога, товара и корзины
├── js/
│   ├── products.js      — ⭐ ГЛАВНЫЙ ФАЙЛ ТОВАРОВ — тут все товары и цены
│   ├── cart.js           — логика корзины (не нужно трогать)

│   ├── catalog.js         — фильтры каталога (не нужно трогать)

    └── hero/                — фото для главной страницы и категорий (заглушки)
```

## 3. Как добавить, изменить или удалить товар

Откройте файл **`js/products.js`** любым текстовым редактором (подойдёт
даже стандартный TextEdit на Mac, но удобнее скачать бесплатный
редактор **VS Code** — vscode.com).

Каждый товар выглядит так — это один блок в фигурных скобках `{ ... }`:

```js
{
  id: 14,                          // уникальный номер (не должен повторяться)
  slug: "moy-novyi-tovar",         // часть ссылки, латинскими буквами, без пробелов
  category: "bahur",               // одна из: bahur, burners, musk, accessories
  name: "Название товара",
  price: 2500,                     // цена в рублях, только число
  oldPrice: null,                  // старая цена для скидки, либо null (нет скидки)
  badge: "Новинка",                // текст плашки на карточке, либо null
  shortDesc: "Короткое описание для карточки товара",
  description: "Полное описание для страницы товара",
  notes: ["Уд", "Амбра"],           // ароматические ноты
  usage: "Как использовать товар",
  inStock: true,                   // true — есть в наличии, false — нет
  rating: 5,
  reviewsCount: 10,
  images: ["images/products/имя-файла.svg"],
},
```

**Варианты объёма/веса (необязательно).** Для бахура на сайте есть выбор
объёма — 40 г / 100 г / 250 г — с разной ценой. Чтобы включить это у
товара, добавьте поле `variants`:

```js
variants: [
  { label: "40 г", price: 1490 },
  { label: "100 г", price: 2890, default: true }, // default: true — вариант, выбранный по умолчанию
  { label: "250 г", price: 6290 },
],
```

Если поле `variants` не добавлять — у товара будет просто одна цена
(поле `price`), без выбора объёма. Так сделаны, например, бахурницы и
аксессуары.

**Чтобы добавить новый товар:**
1. Скопируйте один блок целиком (от `{` до `},`).
2. Вставьте его перед закрывающей квадратной скобкой `];` в конце списка `PRODUCTS`.
3. Измените `id` (поставьте следующий свободный номер), `slug`, `name`, `price`, описание и т.д.
4. Сохраните файл — обновите страницу в браузере.

**Чтобы изменить цену или текст** — просто отредактируйте нужную строчку
и сохраните файл.

**Чтобы удалить товар** — выделите его блок целиком (от `{` до `},`) и удалите.

⚠️ Важно: после `}` каждого товара (кроме самого последнего) должна
стоять запятая `,` — иначе сайт перестанет работать. Если что-то
сломалось после редактирования — проверьте в первую очередь запятые и
кавычки.

## 4. Как заменить фотографии на настоящие

Сейчас вместо реальных фото используются красивые декоративные
заглушки (SVG-иконки на бежевом фоне), чтобы сайт не выглядел пустым.
Обязательно замените их на свои фотографии перед запуском магазина.

1. Сфотографируйте товар (желательно на светлом однородном фоне,
   квадратный кадр 1:1 смотрится лучше всего).
2. Сохраните фото в папку `images/products/` — например, `moy-tovar.jpg`.
3. В файле `js/products.js` в поле `images` товара впишите путь к вашему
   файлу, например:
   ```js
   images: ["images/products/moy-tovar.jpg"],
   ```
   Можно указать несколько фото через запятую — они появятся как
   маленькие превью под основным фото на странице товара.

Так же можно заменить фото категорий (`images/hero/cat-bahur.svg` и
т.д.) и фото на главной странице (`images/hero/about.svg`) — просто
положите свои файлы с теми же именами (можно `.jpg` или `.png`, тогда
не забудьте поменять расширение файла и в HTML-файле, где оно
упоминается — через поиск `Ctrl+F` / `⌘+F` по имени файла).

## 6. Как устроено оформление заказа

Покупатель добавляет товары в корзину, на странице `cart.html` вводит своё
имя и телефон и нажимает «Оформить через WhatsApp». Открывается WhatsApp
с уже готовым сообщением: список товаров, количество, итоговая сумма и
данные покупателя. Дальше вы просто отвечаете клиенту в WhatsApp —
никакой отдельной админки или базы заказов на первом этапе не нужно.

Номер WhatsApp, на который приходит заказ, задан в файле `js/cart.js`
(и в других местах сайта, где есть ссылки на WhatsApp) — замените
`79373447992` на свой номер по инструкции из раздела 5.

## 7. Отзывы, преимущества и текст «О бренде»

Отзывы покупателей на главной странице — реальные, из сообщений
покупателей. Показывается по 3 карточки в ряд на компьютере (четвёртая
открывается стрелкой) и по одной на телефоне. Чтобы добавить новый или
изменить текст отзыва — откройте `index.html`, найдите раздел
`<section id="reviews">` и отредактируйте нужный блок `.review-card`
(текст отзыва, имя и подпись под ним).

## 8. Если что-то не работает

- Убедитесь, что не удалили случайно фигурную скобку `{`, `}`, запятую
  `,` или кавычки `"` в файле `products.js` — из-за одной пропущенной
  запятой может пропасть весь список товаров.
- Откройте сайт через способ Б (локальный сервер) — так меньше шансов
  столкнуться со странностями браузера.
- Если совсем не открывается — можно отменить последнее изменение
  (Cmd+Z в редакторе) и сохранить снова.
